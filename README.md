# 🛒 E-Commerce Sales Analysis

## 📊 Project Overview

SQL-based data analysis project focused on understanding sales performance, customer behavior, and product performance for an e-commerce business.

The project uses Google BigQuery to analyze transactional data and generate business-oriented metrics and insights through SQL queries.

---

## 🎯 Business Objectives

The analysis focuses on answering key business questions:

* How much revenue does the business generate?
* How many orders and units are sold?
* Which products generate the highest revenue?
* Which customers generate the most value?
* Which countries generate the most revenue?
* Which products and categories perform best?

---

## 🗂️ Dataset

The project uses three relational tables:

### Customers

Contains customer information:

* Customer ID
* Customer name
* Country
* Signup date

### Orders

Contains transaction-level information:

* Order ID
* Customer ID
* Product ID
* Order date
* Quantity

### Products

Contains product information:

* Product ID
* Product name
* Category
* Price

The tables are connected through customer and product identifiers.

## 🔍 Analysis Performed

### 1. Sales Analysis

File:

`sql/01_sales_analysis.sql`

The analysis includes:

* Total orders
* Unique customers
* Units sold
* Total revenue
* Average order value
* Monthly revenue trends
* Top products by revenue

Key SQL techniques:

* `JOIN`
* `COUNT`
* `SUM`
* `AVG`
* `GROUP BY`
* `ORDER BY`
* Date functions

---

### 2. Customer Analysis

File:

`sql/02_customer_analysis.sql`

The analysis includes:

* Revenue generated by each customer
* Number of orders per customer
* Units purchased
* Customer revenue by country
* Identification of repeat customers
* Customer revenue ranking

Key SQL techniques:

* Multiple `JOIN`s
* `GROUP BY`
* `HAVING`
* `COUNT(DISTINCT)`
* `RANK()`
* Common Table Expressions (`CTE`)

---

### 3. Product Analysis

File:

`sql/03_product_analysis.sql`

The analysis includes:

* Product sales performance
* Units sold by product
* Revenue by product
* Product performance by category
* Product ranking within categories
* Top products by category

Key SQL techniques:

* `JOIN`
* `GROUP BY`
* `RANK()`
* `ROW_NUMBER()`
* `PARTITION BY`
* Common Table Expressions (`CTE`)
